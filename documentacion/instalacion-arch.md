##Descripcion
se realizo la instalacion de arch linux como sistema operativo base del proyecto, utilizando virtualbox como entorno de desarrollo
##configuracion del sistema
-arquitectura: x86_64.
-firmware: UEFI
-particion EFI : 1G, FAT32, montada en ´/boot´
-particion raiz: 35G, ext4.
-particion de usuario: aproximadamente 15G, ext4.
-gestor de arranque: systemd-boot.
-usuario: miku.
-zona horaria: America/Caracas
-configuracion regional: es_VE.UTF-8.
-distribucion de teclado: latinoamericano
##resultados
-sistema base instalado correctamente
-usuario y permisos administrativos configurados.
-conexion a internet funcional.
-sistema preparado para instalar el entorno grafico y componentes del proyecto
