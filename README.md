#sistema hibrido de contendorizacion android sobre arch linux con interfaz de monitoreo dinamico y asistencia visual
##descripcion
Proyecto orientado al desarrollo de un sistema de computacion basado en linux, con un entorno grafico personalizado e integracion de aplicaciones de android mediante waydroid
##objetivo general
desarrollar un sistema hibrido de contendorizacion android sobre arch linux con interfaz de monitoreo dinamico y asistencia visual
##Tecnologias
-Arch linux
-wayfire
-wayland
-waydroid
-kernel linux
-virtualbox
##Estado del proyecto
-[x]instalacion de arch linux
-[x]configuracion de entorno grafico wayfire
-[x]configuracion de red y acceso a internet
-[]personalizacion visual del sistema
-[]implementacion de la moitorizacion de recursos
-[]integracion del asistente virtual animado
-[]pruebas y documentacion final
##entorno de desarrollo
el sistema se esta desarrollando inicialmente en una maquina virtual mediante oracle virtualbox
