#configuracion del entorno grafico wayfire
##Descripcion
se instalo y configuro wayfire como entorno grafico del proyecto, utilizando el protocolo wayland
##Tecnologias
-wayfire
-wayland
-linux
-arch linux
##actividades realizadas 
-instalacion del entorno grafico wayfire
-configuracion de la sesion grafica
-inicio y comprobacion del entorno de escritorio
-configuracion inicial para continuar con la personalisacion visual
##resultado
se consiguio iniciar correctamente el entorno grafico wayfire, estableciendo la base para integrar los elementos visuales y las funcionalidades adicionales del proyecto.
